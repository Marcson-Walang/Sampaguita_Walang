# Activity 3: Finding the Hypotenuse of a Right Triangle Using the Math Library

## This Project helps in finding the hypotenuse of a right triangle.

## To use it, open the file and enter the length of side A and B to find the hypotenuse.

## You need to input the length of side A and B.

## Example: It asks you what Side A and B is, you enter 34 and 45. It tells you the hypotenuse is 56.40 and rounds it to the second decimal place.
