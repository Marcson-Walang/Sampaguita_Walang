# Activity 2: Finding the distance between two points.

## This program helps in calculating the distance between two points in a single plane.

## To use it, you simply need to open it, input the values of x1, y1, x2, and y2 and it will calculate the distance between the two points using the distance formula and give the results.

## You need to input the values of x1, y1, x2, and y2.

## Example: You enter 5 as the values for x1 and y2 and 4 as the values for x2 and y2, The program will compute the distance and give the answer which is 1.41
